# 按任务选择技能

下面是便于起步的任务与技能对应关系。英文编号可直接交给安装脚本；具体能力和依赖以该技能说明为准。

| 你的任务 | 建议先看 | 主要产出或作用 |
|---|---|---|
| 做出版社、企业或项目网站 | `web-design-engineer`、`frontend-design` | 页面设计与前端实现 |
| 把现有页面改得更专业 | `redesign-existing-projects`、`design-taste-frontend` | 结构、视觉与组件改进 |
| 让AI准确理解弹窗、卡片展开等交互 | `ui-interaction-brief` | 可实现、可验收的交互说明 |
| 找滚动动画和三维网页参考 | `web-motion-reference` | 动效案例、关键词与实现线索 |
| 实现滚动动画 | `gsap-core`、`gsap-scrolltrigger` | 页面动画与时间线 |
| 制作汇报PPT | `ppt-master`、`html-ppt` | 演示页面及相应导出材料 |
| 把幻灯片截图恢复成可编辑PPT | `gordenimage2pptx` | 背景、可移动元素与可编辑文字 |
| 从主题生成视觉PPT再还原可编辑文件 | `gordensuperpptskill`及两个子技能 | 图片版与可编辑版PPT |
| 把资料排成精美长文章 | `beautiful-article` | 可离线分享的HTML文章 |
| 模仿已有品牌语气写专业文章 | `ecc-brand-voice`、`ecc-article-writing` | 风格说明和长文草稿 |
| 研究同类产品或平台 | `ecc-competitive-platform-analysis`、`ecc-market-research` | 竞品范围与有来源的研究结果 |
| 批量整理网站内容 | `firecrawl-map`、`firecrawl-crawl`、`firecrawl-download` | 链接清单、结构化内容与本地资料 |
| 建立或维护本地资料库 | `llm-wiki`、`kb-retriever` | Wiki页面、资料检索与问答 |
| 将一本书或课程转成可复用技能 | `cangjie-skill` | 从材料提炼的技能集合 |
| 从教材电子稿制作详情页 | `textbook-detail-page` | 灵枢医学数字教材HTML详情页 |
| 按知识前置关系安排学习 | `prerequisite-learning-path` | 学习顺序、缺项与练习任务 |
| 分析业务数据与指标变化 | `data-analytics--metric-diagnostics`、`data-analytics--build-report` | 指标诊断与分析报告；需适配数据工具 |
| 制作交互图表与仪表盘 | `build-web-data-visualization--data-visualization` | 图表方案、交互和可视化实现 |
| 多人协作开发时沉淀规范 | `openspec-propose`、`ecc-context-and-decisions` | 规范、计划与决策记录 |
| 修改代码前确认影响 | `ecc-change-impact`、`review-agent` | 变更影响分析与缺陷报告 |
| 排查难复现问题 | `superpowers--systematic-debugging` | 有证据的定位流程 |
| 做iOS或macOS应用 | `build-ios-apps--swiftui-ui-patterns`、`build-macos-apps--swiftui-patterns` | SwiftUI实现建议与工程改进 |
| 预览三维模型 | `open-model-workbench` | 本地模型预览工作台 |
| 训练或评测开源模型 | `hugging-face--llm-trainer`、`hugging-face--community-evals` | 训练与评测流程；需独立计算环境 |
| 整理云端团队资料 | Google Drive、Notion或Pages系列 | 文件、页面、数据库与纪要；需对应授权 |

选择原则：优先使用能直接解决当前任务的一个入口；确实有编排或依赖关系时再加入其他技能。不要把多个不同来源的同名技能一次装到同一个目录。
