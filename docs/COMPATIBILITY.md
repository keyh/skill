# 兼容性与依赖

`SKILL.md` 是文本入口，其他 AI 能阅读它不代表能运行其中所有工具。目录和 JSON 清单对每个入口给出了兼容性标签与依赖说明。

| 类型 | 能迁移的部分 | 需要另外准备的部分 |
|---|---|---|
| 文本工作流 | 规划、写作、设计、审查等流程 | AI需支持读取技能文件，且仍应遵守当前任务授权 |
| 脚本或工具依赖 | 指引、脚本、模板与资源 | Python、Node、浏览器或特定CLI；版本以技能要求为准 |
| 工具与环境适配 | 插件内的技能包与共享参考 | 工具名称、项目路径、操作系统与插件命名空间 |
| 平台或插件依赖 | 可保留的技能材料 | 原平台工具、MCP、连接器、账号权限或本地应用 |
| 平台限制，不复制 | 本仓库提供的用途与获取说明 | 在原平台中使用，不从本仓库安装正文 |

## 不复制正文的技能

**`documents--documents`：Word文档排版、修订与校验。**

本机这项技能的 `LICENSE.txt` 明确限制从服务中提取、在服务外保留或复制材料。因此本仓库仅保留这一用途说明和目录记录，没有复制它的 `SKILL.md`、脚本、资源或许可全文。请在已获授权的 Codex 官方文档功能中使用。安装器会明确拒绝安装此目录项。

## 保留原文的适配事项

原始 `SKILL.md` 保持字节一致，原有安全约束与调用方式也保留。有些技能含有专用工具标识、插件变量或本机路径，例如 `lucian-uxui` 存在历史安装路径；在新环境中需要映射到实际目录。不要直接把不存在的路径视为已配置。

Superpowers、OpenSpec等系列存在互相引用。选定一个入口时，完整包的支持材料可能需要一起保留；本仓库的插件安装方式为此保留了整个来源包。业务运行依然应先确认必需的兄弟技能和工具。

## 当前验证边界

已验证的是文件整理、原始技能入口哈希、安装器的复制/链接行为及选定的共享引用。没有启动各插件服务，没有批量执行技能里的业务操作，也没有验证所有第三方AI的自动发现机制。不要把“源文件已收录”理解为“跨平台全部功能已经实测可用”。
