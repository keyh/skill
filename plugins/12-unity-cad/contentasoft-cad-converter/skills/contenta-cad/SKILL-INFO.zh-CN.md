# Contenta CAD：CAD与网格文件转换

Contenta CAD：CAD与网格文件转换。适用于游戏、编辑器、场景、音频、渲染和三维文件转换相关任务；具体输入、步骤和输出见原始技能说明。

- 仓库唯一编号：`contentasoft-cad-converter--contenta-cad`
- 原始技能名：`contenta-cad`
- 分类：Unity与CAD
- 兼容性：平台或插件依赖
- 依赖：保留 Contenta CAD 整包目录；阅读 SKILL.md 确认所需工具。复制技能文件不会安装插件、MCP、CLI或账号授权。
- 许可：MIT
- 来源：Contenta CAD 插件 1.0.3

## 原始说明

Convert 3D CAD and mesh files with the 3D CAD Converter CLI (cadconvert). Use when the user asks to convert STEP, IGES or BREP to STL, OBJ, 3MF, glTF/GLB, FBX, PLY or other formats, convert between mesh formats (including USD/USDZ and VRML input), change units, control mesh quality for 3D printing, reduce the polygon count of a mesh, set the up axis for game engines, inspect a 3D file, or batch-convert or watch a folder of CAD files.
