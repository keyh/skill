# Unity：UI Toolkit界面

Unity：UI Toolkit界面。适用于游戏、编辑器、场景、音频、渲染和三维文件转换相关任务；具体输入、步骤和输出见原始技能说明。

- 仓库唯一编号：`unity--ui-uitk`
- 原始技能名：`ui-uitk`
- 分类：Unity与CAD
- 兼容性：平台或插件依赖
- 依赖：保留 Unity 整包目录；阅读 SKILL.md 确认所需工具。复制技能文件不会安装插件、MCP、CLI或账号授权。
- 许可：Unity Companion License
- 来源：Unity 插件 0.1.0-beta

## 原始说明

Unity UI Toolkit expert for Unity 6.0+. Understands, edits, and generates UXML and USS files with flex-based layouts. Use for requests involving .uxml, .uss, UI Toolkit, UIElements, UIDocument, UI runtime binding, Custom UI Elements, Manipulators or PanelSettings.
