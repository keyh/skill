| 形式 | 主要关系 | 要写清的区别 |
|---|---|---|
| Tooltip | 控件与一句解释 | 聚焦/悬停可见，不塞入需要操作的复杂内容 |
| Popover | 锚点与局部信息 | 可有少量操作，关闭条件独立说明 |
| Dropdown | 触发器与候选列表 | 选中后行为、键盘移动、危险选项语义 |
| Modal | 必须处理的决定 | 背景不可操作、确认与取消结果 |
| Drawer | 原页面与侧边详情 | 是否模态、编辑未保存的处理 |
| Bottom Sheet | 手机触发与底部面板 | 操作可触达、拖动/滚动/退出关系 |
| 纵深叠牌 | 前后层级 | 拉开深度，选中前移，关闭归位 |
| 扇形 | 共同支点 | 改变角度，选中抬起，回原扇面 |
| 圆柱 | 同一圆周 | 整组旋转，前后遮挡，选中面向用户 |
| 球面 | 多方向分布 | 整球转动、保持朝向，关闭回原位置 |
| 螺旋 | 转角与高度同时变化 | 叙述顺序与层级一致，不能退化为互不相关的圆环 |
| 波浪网格 | 固定行列与变化高度 | 保持行列，按次序起伏，选中卡片独立查看 |

不要把表现形式当成固定实现：CSS 变换、二维模拟或真正三维场景都可能符合画面，需要项目性能与交互验证才能判断。
