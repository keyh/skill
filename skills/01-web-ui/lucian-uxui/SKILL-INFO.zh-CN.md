## 原始说明

Builds sites, pages and components from Lucian UX/UI Prompt (lucianlabs.dev/uxui-prompt), a growing library of polished, dependency-free interactive UI elements with light and dark themes, keyboard and touch support and reduced motion. It covers buttons, toggles, inputs, menus and tabs, cards, sign-in and sign-up, toasts, loaders, empty and error states, charts, app-level tools like editors, dashboards, schedulers and kanban boards, and website sections and motion such as heroes, pricing, testimonials, sign-up forms, text and scroll animations, product showcases and animated charts. Searches the library, fetches only the chosen elements and ports them into the project's framework and theme. Use when the user names lucian-uxui, Lucian UX/UI or lucianlabs elements, or asks to build UI that should use them, e.g. "build a landing page with lucian-uxui", "lucian-uxui 스킬로 사이트 만들어줘", "루샨 UX/UI 요소로 로그인 화면 만들어줘". Not for backend work or for editing the library itself.
