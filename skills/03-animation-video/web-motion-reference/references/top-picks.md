# 按用途的精选（起步清单）

从 1813 条里按「灵枢适配度、网页可用度」排出的前几名，作为检索的起点，不是唯一答案。每条 id 都可以用 `scripts/search.py --show <id>` 看全部字段、`--poster <id>` 看图。

每个用途分三组：**可取代码**（A 级开源示例与 three.js 官方示例）、**有条件可用**（B 级，只放链接）、**只借思路**（Opus 合集，C 级，需要重新实现）。
