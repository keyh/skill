# 灵枢医学数字教材：视觉调性与动效约束

适用范围：中国中医药出版社「灵枢医学数字教材」平台的所有页面（门户首页、登录与身份、教材库、教材详情、学生端 / 教师端工作台、宣传短片）。信息来自项目文档《首页与登录_three.js视觉方案与场景提示词》《灵枢医学数字教材首页_Vue3工程说明》，截至 2026-10-12。项目有新决定时，以项目文档为准。

## 一、调性

- **庄重、典雅、学术为底，带一点东方意味和“AI 时代”的科技感**。用户是院校、教师、学生和采购方，页面要可信、耐读，不能像游戏或发布会。
- 品牌意象：黄帝内经、天枢与北斗、开阖枢；“经络”是灵枢独有的符号，可以转译成沿曲线流动的光点或细线。
- 色彩：深海军蓝底 `#061430 → #0a2350`，品牌青 `#5fdbff`，辅助蓝 `#2f6ff0`，点缀紫 `#a08fff`。七个身份各有身份色（见工程 `components/common/roleMeta.js` 的 `roleVars(role)`），场景随身份切换时渐变到身份色。
- 东方元素（水墨、宣纸、竖排、朱印）适合宣传短片、栏目头图和品牌页；工作台、表单页要克制，只用纸纹或极淡的笔触做底。
- 内容必须真实：用产品真实信息（7 个身份、工作台功能、教材数据），不要虚构数据或客户。

检索时常用的过滤组合：`--tone 沉静,典雅,东方,学术 --min-fit 4`。

## 二、three.js 用在哪里、不用在哪里

**适合**
| 效果 | 用在哪里 |
|---|---|
| 粒子场 / 光点海（Points + 自定义着色器） | 首页首屏背景 |
| 沿曲线流动的粒子（CatmullRom 曲线 + 粒子） | “经络光流” |
| 噪声起伏的粒子球（Simplex 噪声） | 灵枢AI 的形象，“思考”时加速变亮 |
| 隧道光线 + 光环 | 切换身份页的“光门” |

**不建议**：整页 3D 模型、物理引擎、后期辉光（Bloom）、全屏着色器。它们体积大、耗电，对教材和采购这类商务场景帮助不大。参考案例用了 Bloom 时，改用加色混合的柔和圆点模拟光晕；确实需要全屏着色器（如纸纹、流雾）时，先跟用户确认，并保证有 CSS 降级。

文字、按钮、表单一律是普通 HTML，three.js 只做背景和氛围。

## 三、工程约束（硬性）

**技术栈**：Vue 3.5（`<script setup>`，构建时预渲染 + 浏览器端激活）、vue-router 4、Pinia、Vite 6、three 0.185.1（固定版本）。代码仓库 GitHub `keyh/Claude-lsdb`。

**3D 加载与运行**
- three.js 按需加载：页面 `load` 之后、浏览器空闲时才下载，单独成块；下载完成前显示原有 2D / CSS 效果。
- `src/three/lib.js` 只导出用到的 three 类（约 130KB gzip）。新场景需要别的类，在这里补导出，不要整包引入。
- 只在支持 WebGL 2 时启用；开启“省流量”（`navigator.connection.saveData`）时不加载。
- 低配设备（内存 ≤2GB 或核心 ≤2）与手机一样减量，粒子约减半；像素比封顶（桌面 1.75，紧凑 1.5）；紧凑模式 30fps。
- 离屏、页面隐藏、暂停、系统“减少动态效果”时停止逐帧绘制，只画一帧静态画面。
- 场景接口统一走公共外壳 `useThreeStage`，见 `recipes/README.md`。

**兼容性**
- 要兼容 Chromium 64+ 的 360、QQ 极速内核、微信 X5，构建有降级包（`@vitejs/plugin-legacy`），CSS 目标 `chrome64`。
- 不要用 `color-mix()`，半透明身份色写成 `rgba(var(--rg-rgb), .5)`。
- `aspect-ratio` 决定高度时配 `@supports not (aspect-ratio:1/1)` 的 padding 兜底。
- `animation-timeline`（滚动驱动动画）和 View Transitions 只能做渐进增强，用特性检测，保留静态结果。
- 项目没有引入 Tailwind。Inspira UI、Vue Bits、Magic UI、Aceternity、Animata 这些基于 Tailwind（多为 v4，要求 Chrome 111+）的组件只能当源码蓝本，接入前改写成 scoped CSS。GSAP、Anime.js、motion-v、NumberFlow、Lenis 不受影响。

**性能与体验**
- 首屏内容在 HTML 里直接可见，动效不阻塞首屏；楼层动效进入视口才激活。
- 可切换区域预留最大高度，切换时页面不跳动。
- 全站页面在任何桌面宽度下都保留左右留白，采用整页等比缩放。
- 平滑滚动（如 Lenis）只用在首页叙事楼层，正文阅读区保留原生滚动。

## 四、已上线的场景（可直接复用或改造）

| 场景 | 位置 | 要点 |
|---|---|---|
| 首屏「知识星河」 | 首页首屏 | 190×78 光点海三层正弦起伏；4 条经络曲线各 300 个流动光点汇向登录卡；知识节点脉动；`setRole(身份)` 渐变到身份色；`pulse()` 涟漪；输入框聚焦时降速到 22% 并变暗；鼠标视差 ±1.4 |
| 灵枢AI「AI 核心」 | 首页灵枢AI 楼层 | 约 4200 点斐波那契球面，3D Simplex 噪声改半径；颜色 `#2f6ff0 → #5fdbff`，顶部偏 `#a08fff`；两条反向粒子轨道；`setBusy(true)` 起伏加大、转速 ×3 |
| 切换身份「光门隧道」 | 切换身份页 | 1600 点旋转光环 + 2200 条迎面光线，消失点对准中间的门；推门时光线拉长 9 倍、提速 20 倍，光环变身份色；缓动 `cubic-bezier(.16,1,.3,1)` |

源码在 `recipes/lingshu-three/`，接口与接入方法见 `recipes/README.md`。做新场景时，优先在这三个的基础上改，保持同一套外壳和性能规则。

## 五、可能用得上的方向（来自参考库的高分案例）

- 知识图谱：3d-force-graph 的文字节点、连线流动光点（`vasturiano-3d-force-graph/*`）做氛围图谱；严肃可读的 2D 结构用 AntV G6（`antv-g6/*`）。
- 东方质感：程序化水墨（`ink-wash-procedural/*`，MIT）、Paper Shaders 的纸纹与颗粒渐变（Apache-2.0）、TSL Textures 的湍流烟（像墨入水）。
- 讲解动画：可拆解的 3D 器物、分层剖面、逐步描线（如 opus 池 `aichrislee-378670`、`thebuggeddev-482912` 的做法，只借思路）。
- 教材目录：three 池 `css3d_periodictable` 的卡片在表格、球、螺旋之间变换，可改成药材或章节卡片。
