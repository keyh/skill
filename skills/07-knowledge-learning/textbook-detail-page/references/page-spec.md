# 页面规格（详情页 V27）

本文说明模板页面是什么、各栏目显示什么、设计标准是什么。目的有两个：撰写文案时知道每段话出现在哪里、有多长的空间；评审或修改模板时有依据。**生成单本教材时不需要改模板。**

## 结构

```
顶栏（平台公用）
首屏：3D 封面 + 书名信息 + 售前 AI 咨询条 + 获取卡（学生 / 教师 / 院校三个选项卡）
数据带：数字版本 · 知识体系 / 能力体系 / 问题体系 / 教学资源 四个数字 · 使用数据（新书显示“新书上线”）
身份卡：学生选购 / 教师选用 / 院校审选
一级栏目条（吸顶，每种身份 12 个栏目，每个栏目是独立页面）+ 吸顶转化条
页头（栏目名 + 一句话说明）
二级锚点条（吸顶）
内容块 ×2–5
获取这本教材（三身份卡）
页脚（平台公用）
```

## 三种身份 × 12 个栏目

| 学生选购 | 教师选用 | 院校审选 |
|---|---|---|
| 教材导读：教材简介 / 适用对象 / 学习目标 / 使用方法 / 版本信息 | 选书总览：选用摘要 / 教材规模 / 核心优势 / 推荐理由 | 审选总览：审选摘要 / 基本条件 / 建设规模 / 审选结论 |
| 核心数据：体系总览 / 资源构成 / 项目分布 | 课程适配：适用专业 / 课程定位 / 课程标准 / 学时建议 | 出版资质：出版身份 / ISBN 版次 / 数字版本 / 更新记录 |
| 内容导航：目录全景 / 项目任务 / 重点难点 | 编研团队：主编主审 / 编写团队 / 单位分布 | 编审机制：编写流程 / 审校流程 / 数字内容审核 |
| 知识图谱：知识网络 / 支撑技能 / 学习路径 | 岗课赛证：融通矩阵 / 岗位画像 / 证书赛项 / 课程标准 | 编研团队（同教师） |
| 能力图谱：五级结构 / 能力进阶 / 岗课赛证 | 知识图谱（教学路径） | 标准适配：专业标准 / 职业标准 / 技术标准 / 适配结论 |
| 问题图谱：问题三层 / 问题链条 | 能力图谱 | 内容质量：质量六性 / 图谱体系 |
| 思政图谱：思政主线 / 项目映射 | 问题图谱 | 岗课赛证（同教师） |
| 任务体验：任务体例 / 任务样例 / 成果要求 | 思政图谱 | 资源建设（同资源） |
| 赛证直通：融通矩阵 / 对接证书 / 对接赛项 / 覆盖明细 | 教学应用：教学计划 / 教学建议 / 课堂样例 / 纸数融合 | 应用证据：使用规模 / 学期趋势 / 教学数据 / 反馈 |
| 配套资源：资源总览 / 媒体资源 / 题库资源 | 教学资源 | 成果价值：规划与奖项 / 建设借鉴 / 成果材料 |

每个内容块带 `data-src` 标记内容来源：`manual` 人工录入 · `parse` 稿件解析 · `ai` AI 生成已审核 · `live` 平台数据。映射表在模板的 `SRC` 常量里，按块标题匹配。

## 知识图谱与能力图谱（教职成〔2026〕1 号文）

- **能力图谱**回答“学完能做什么”，五级线性结构：项目 → 任务 → 流程 → 技能点 → 知识点。
  - 五级结构块：全书规模条（五级各一个数字）+ 项目选择条 + 当前项目的五条泳道（图谱视图）或表格视图（1 号文认可的核心形式）。底部为素养点（评价表中的素养类维度 + 思政园地）与赛证直通。
  - 能力进阶块：当前项目【能力图谱】表，按 认知层 → 实践层 → 拓展层 三列。
  - 岗课赛证块：各证书对接比例环 + 逐任务对接明细表（实心点 = 作者写明；虚线点 = 补写待确认，不计入）。
- **知识图谱**回答“知识在哪里”，网状：
  - 知识网络：项目围成环，每个项目外侧是它的知识点，弧线是跨项目关联；点项目或知识点看它支撑的技能点与关联。
  - 支撑技能：当前任务的知识点 → 技能点（评价标准）对应。
  - 学习 / 教学路径：编者自下而上构建、学生自上而下学习；两张图谱分工表。
- **院校 · 图谱体系**：对照 1 号文的 10 项自查，能从稿件算的自动给出“已具备 / 部分具备”，稿件里没有的（企业参与佐证、年度复盘）标“待补充”。

## 状态

| 情况 | 数据 | 页面表现 |
|---|---|---|
| 新书 | `live: null` | 数据带显示“新书上线 · 首批选用院校招募中”；应用证据四块为空状态；审选摘要改措辞 |
| 未入规划 | `meta.plan: null` | 首屏规划标签隐藏；规划与奖项、基本条件显示“申报中” |
| 首个数字版本 | `meta.versions` 一项 | 版本时间线三段；更新记录显示“首个版本” |
| 无能力结构 | `capability: null` | 知识图谱、能力图谱、融通矩阵、图谱体系显示“尚未从稿件导入”占位 |

`build_page.py --new-book` 一次生成新书状态页面，用于教材上线前的演示。

## 设计标准

- 配色：主蓝 `#165bd4`、字色 `#142c4a`、正文 `#344b64`、次要 `#607185`、浅底 `#f3f7fc`、线 `#d7e1ec`；图表调色板 `#4f7df3 #35b37e #8b6cf0 #ef5e9c #f29a3a #2bb5c9`；身份色 学生橙 / 教师绿 / 院校蓝。
- 字体：系统字体栈，无字体文件；数字用等宽变体。
- 卡片：圆角 14px，发丝边 + 低阴影；不用纯白整页底（页面底 `#eef2f9`）。
- 可视化全部为 SVG / CSS，由数据驱动：项目环、资源环图、项目分布柱图、三环目标图、问题图谱三列连线、知识网络、五级泳道、能力进阶矩阵、对接明细点阵、热力图。
- 动效：数据带数字滚动、内容块进场、环图 / 条形生长、图谱描线；遵循 `prefers-reduced-motion`。
- 响应：1200 宽为设计基准；≤ 1000 栏目条可横向滚动；≤ 760 图谱改单列，知识网络横向滚动并居中；390 宽无横向溢出。
- 无障碍：栏目条 `role=tab` + 方向键；图表 SVG 带 `title`；按钮有文字。
- 单文件：无第三方库；Logo 为内嵌 SVG；体积约 350 KB（能力结构数据约 130 KB）。

## 与门户 Vue 工程的关系

门户工程 `apps/portal` 的 `/books/:id` 是同一设计的 Vue 实现，组件按栏目拆分（`src/views/books/detail/`）。单文件页面用于评审与演示；上线用 Vue 工程。两者数据同源：`to_vue.py` 把 `book.json` 转成工程的 `bookDetail` / `bookCapability` 条目。
