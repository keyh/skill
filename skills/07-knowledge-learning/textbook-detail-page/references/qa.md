# 交付前检查

## 自动检查（必须通过）

```bash
python3 -I build_page.py book.json 详情页.html         # 字段完整性、项目 / 阶段 / 简称一致性
node scripts/check_page.js 详情页.html                  # 两种宽度 × 36 个栏目
```

`check_page.js` 检查：无 JS 报错与控制台错误；无横向溢出；每个内容块有内容；页面文本里没有 `undefined` / `NaN`。

## 数据一致性

- [ ] `assemble.py` 打印的任务 / 知识点 / 技能点 / 思政 / 赛证 / AI 数量，与你在文案里写的数字一致（`guideLead`、`lead`、`teacherSummary`、`teacherFit`、`standardConclusion`、`qualitySix`）。
- [ ] 每个项目的任务数与稿件目录一致；任务标题没有多抽（步骤被当成任务）或少抽。
- [ ] 能力结构：没有空维度、没有被斜杠拆开的条目；评价表分值异常的任务已在交付说明里列出。
- [ ] 赛证对接率只计作者写明的；补写的在 `pending.txt` 里，页面显示“待作者确认”。
- [ ] `stages` 覆盖全部项目；`short` 数量等于项目数且每个 ≤ 5 字。
- [ ] 新书：`live: null`、`meta.plan: null`、`feedback: []`，不出现任何虚构的使用数据或反馈。

## 人工走查（打开 HTML）

三种身份各点一遍 12 个栏目，重点看：

- [ ] 首屏：书名两行封面不换行溢出；信息栏没有“待补充”以外的占位；价格方案与层次匹配。
- [ ] 教材导读：项目环标签不重叠（项目数 > 20 时简称要更短）；阶段卡颜色区分。
- [ ] 内容导航：目录里每个项目的简介是正文，不是批注；重点难点与教材内容对得上。
- [ ] 能力图谱：切换项目和任务，流程、技能点、知识点都有内容；表格视图可读；能力进阶有三层。
- [ ] 知识图谱：点项目、点知识点、点“在其他项目中的关联”能跳转；手机宽度可横向滚动。
- [ ] 岗课赛证 / 赛证直通：证书名称与稿件一致；明细表每行有点。
- [ ] 问题图谱、思政图谱、任务样例：文案与稿件情境对得上，没有另一本书的残留（搜索示例书名与病名）。
- [ ] 教师端、院校端：团队、政策、标准表为本书内容；“待补充”项有说明。
- [ ] 390 宽：栏目条可滑动，图表可横向滚动，没有被截断的文字。

## 交付说明模板

```
《书名》数字教材详情页 · 生成说明
1. 数据来源：稿件 N 个项目文件（版本 / 日期）；抽取统计：项目 x、任务 x、流程 x、技能点 x、知识点 x、思政 x、赛证 x。
2. 规划值（非稿件统计）：视频 / 课件 / 文档 / 图像 / 试题 / 案例 数量，来源为 ____。
3. 待编辑审核的文案：简介、重点难点、问题图谱、思政主线、岗位画像、适配结论、推荐理由。
4. 待作者确认：补写的赛证对接 x 处（见 pending.txt）；稿件问题：____。
5. 未提供的信息（页面留空 / 占位）：____。
```
