# 来源：Marble os-taxonomy 与 zhulin025 的 3D 可视化

调研日期 2026-10-12。以下用自己的话概括，数据与原文以仓库为准。

## Marble Skill Taxonomy（withmarbleapp/os-taxonomy）

- **是什么**：Marble（Generative Spark, Inc.）开源的小学阶段学习图谱，覆盖约 4–13 岁。v1 有 1,590 个微知识点、3,221 条先修关系，分属 8 个学科（科学 547、数学 503、英语 286、历史 90、个人与社会发展 88、生活技能 37、计算机 21、学会学习 18）。在线浏览：withmarble.com/curriculum。
- **数据文件**（`data/`，UTF-8 JSON，附 JSON Schema 和校验脚本）：
  - `topics.json`：节点。每个节点有类型（5 类）、学科、领域、名称、描述、适用年龄段、中心度、2–3 条达标证据、一句检测问题、对接的课程标准编号。
  - `dependencies.json`：边。“某节点依赖某先修”，分硬 / 软（约 2025 条硬、1196 条软），每条带一句理由。
  - `curriculum-standards.json`：7 套课程标准的条目（英国国家课程、美国共同核心、NGSS 等）。
  - `clusters.json`：183 段按（学科、领域、年龄段）写给家长的导读。
  - `manifest.json`：计数与校验和。
- **值得借鉴的设计**：
  1. 粒度定在“一个可教的想法”，每个节点都配可观察的证据和检测问题，可以直接用于评估和 AI 对话；
  2. 先修边分硬软并写理由，既能算学习路径，又能让人审核；
  3. 课程标准对接只是一个属性，图本身按“学习的逻辑”组织，不按教材目录；
  4. 对第三方版权受限的课程标准只存编号，不存条文，并在 PROVENANCE 里逐个写清来源许可；
  5. 数据就是纯 JSON，无运行时依赖，谁都能接。
- **怎么做出来的**：Marble 用 AI 代理从多套课程标准中组装图谱，再经人工审核后发布；仓库里只有结构化数据，没有向量、推荐模型或对话逻辑。先修关系是 AI 辅助加人工整理的结果，不是从教材自动抽取的完美答案；年龄段只是大致参考。
- **对 AI 教育系统的三种用法**（用户提供的公众号文章《AI教育缺的不是大模型，而是一张能转的 Three.js 知识地图》的归纳）：
  1. 路径计算：给定已掌握的知识点，算出当前可学的“前沿”；
  2. 解释性推荐：推荐时说出理由，理由就是先修边上那句话；
  3. 标准对齐检查：把 AI 生成的内容或练习映射回真实的课程标准，而不是依赖模型记忆。
  本 skill 分别对应 `analyze.py --frontier`、边的 `reason` 字段、`standards` 对接编号。
- **我们的调整**：年龄段换成教材的项目 / 章；增加出处 `anchors` 与审核状态 `status`；对接对象换成 1 号文五级结构里的技能点、任务和岗课赛证；校验增加了循环检测、冗余边、编排顺序冲突和覆盖率（原仓库的校验脚本不查循环）。
- **许可**：
  - 数据库（结构、编号、关系）是 ODbL 1.0：可商用，须署名；对**数据库本身**的修改或派生须继续按 ODbL 开放；在产品里使用（产出的作品）不受此限。
  - Marble 撰写的文字（名称、描述、证据、检测问题、理由、导读）是 CC BY-SA 4.0。
  - 课程标准条目各自沿用上游许可，部分只给编号。
  - **对我们的含义**：借用方法和字段设计不产生义务；如果把 Marble 的节点或文字搬进我们的图谱，就构成派生数据库和改编作品，需要署名并按同样许可开放。所以教材图谱一律用自己的数据。若在文档中提到这套方法，署名为“Marble Skill Taxonomy (v1) · © Generative Spark, Inc. (Marble) · ODbL 1.0 / CC BY-SA 4.0”。

## zhulin025/os-taxonomy（3D 可视化）

- 数据与 Marble v1 完全相同，增加了一个单页 3D 可视化（`index.html`，基于 three.js 与 3d-force-graph）和中文说明。
- **可借鉴的交互**：
  - 三种布局：按年龄分层的锥形（底小顶大，体现进阶）、球面、圆环，切换时平滑过渡；
  - 点选节点后，先修链和解锁链分别用冷色、暖色高亮，连线上有流动光点表示方向；
  - 选中节点及其关联节点显示悬浮标签；
  - 按学科、年龄段筛选，左侧有统计；中英文名称搜索并定位；深浅色主题切换；点选时镜头平滑聚焦，场景缓慢自转；
  - 依赖库放在本地，离线可用。
- **不要照搬的地方**：
  - 页面引入了第三方统计脚本（vibeloft.ai），会把访问数据发到外部；
  - 选中节点时把英文内容发给谷歌的非官方免费翻译接口，国内不可用，也会把内容外发；
  - 仓库没有给可视化代码单独声明许可（仓库里的许可文件是 Marble 针对数据和文字的），代码按“只看思路”处理。
- 本 skill 的 `assets/kg-viewer.html` 是按这些交互思路重新写的，基于 MIT 许可的 3d-force-graph，不含外发请求；“按先修分层”用的是 3d-force-graph 自带的有向无环图分层布局。
