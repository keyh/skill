# Dashi主题式HTML与PPT制作

Dashi主题式HTML与PPT制作。适用于汇报材料、可编辑幻灯片、图片转PPT和网页演示相关任务；具体输入、步骤和输出见原始技能说明。

- 仓库唯一编号：`dashi-ppt`
- 原始技能名：`dashi-ppt`
- 分类：PPT与演示
- 兼容性：脚本或工具依赖
- 依赖：按 SKILL.md 安装和配置所需运行环境；本仓库安装器只复制文件，不执行技能脚本或启用后台功能。
- 许可：AGPL-3.0；嵌套组件以各自许可为准
- 来源：https://github.com/chuspeeism/dashi-ppt-skill

## 原始说明

制作 PPT、演示文稿、幻灯片、汇报材料时使用。Dashi PPT 基于预置视觉主题组合页面,生成可离线打开、可在浏览器编辑的 HTML 演示,支持导出 PPTX / PDF 文件。
