# 网页交互与动态内容读取

网页交互与动态内容读取。适用于网页检索、站点采集、文献研究和竞争分析相关任务；具体输入、步骤和输出见原始技能说明。

- 仓库唯一编号：`firecrawl-interact`
- 原始技能名：`firecrawl-interact`
- 分类：搜索与研究
- 兼容性：脚本或工具依赖
- 依赖：需要 Firecrawl CLI 及独立登录或 API 授权；部分操作会使用外部服务额度。
- 许可：本地未发现完整许可文件；不视为获得额外授权
- 来源：https://github.com/firecrawl/skills

## 原始说明

Drive a live browser on a scraped page: click, fill forms, log in, paginate, infinite-scroll. Use when content requires interaction or a scrape failed or returned incomplete content.
