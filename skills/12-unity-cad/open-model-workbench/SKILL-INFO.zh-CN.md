# 本地三维模型工作台

启动本地三维模型工作台，查看模型、材质和场景；用于三维资产检查与预览。

- 仓库唯一编号：`open-model-workbench`
- 原始技能名：`open-model-workbench`
- 分类：Unity与CAD
- 兼容性：脚本或工具依赖
- 依赖：按 SKILL.md 安装和配置所需运行环境；本仓库安装器只复制文件，不执行技能脚本或启用后台功能。
- 许可：MIT
- 来源：https://github.com/icejyzy0430/open-model-workbench

## 原始说明

Open a ready-to-use local 3D model composition workbench for GLB or GLTF files. Use when the user says "打开模型工作台", asks to place, rotate, scale, arrange, or frame one or more 3D models, or needs a clean composition screenshot before website or Image 2 design. If the user has not supplied a model, request GLB/GLTF files first; after models are available, generate the workspace, start its localhost server, and open it automatically.
