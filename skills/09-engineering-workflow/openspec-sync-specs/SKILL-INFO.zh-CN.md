# OpenSpec规范同步

OpenSpec规范同步。适用于需求规划、规范协作、调试、测试、审查和交付相关任务；具体输入、步骤和输出见原始技能说明。

- 仓库唯一编号：`openspec-sync-specs`
- 原始技能名：`openspec-sync-specs`
- 分类：开发流程与质量
- 兼容性：脚本或工具依赖
- 依赖：需要 OpenSpec CLI 和目标项目规范目录；本仓库不启用项目 hooks。
- 许可：MIT
- 来源：https://github.com/Fission-AI/OpenSpec

## 原始说明

Sync delta specs from an OpenSpec change to main specs. Use when the user wants to update main specs with changes from a delta spec, without archiving the change. Also use when the user says "openspec sync" or "opsx sync".
